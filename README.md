# Kotobareach（コトバリーチ）

話した日本語は英語に、相手の英語は日本語に。翻訳した字幕を、手元のスマホやタブレットに表示する Windows 用の無料アプリです。
ゲームのボイスチャットなどで、英語のやり取りを手助けします。

*A free Windows app that turns your spoken Japanese into English subtitles, and the English you hear on your PC into Japanese subtitles — shown on your phone or tablet. (Japanese UI only.)*

## できること

- **自分の声**：マイクで話した日本語を文字にして、自然な英語に訳します
- **相手の声（聞き取り）**：パソコンから聞こえる英語（ゲームの VC、Discord など）を、日本語の字幕にします
- **スマホ・タブレットに字幕を表示**：同じ Wi-Fi のブラウザで開くだけ。英文をタップすると、その端末が読み上げます
- GPU があれば、音声認識が速くなります（NVIDIA / AMD / Intel）

## ダウンロードと使い方

1. [Releases](https://github.com/retzrs-ops/Kotobareach-release/releases/latest) から、最新の **`Kotobareach_Setup_v〇〇.exe`**（インストーラー）をダウンロードして実行します。管理者権限は、いりません。
   - 青い警告「WindowsによってPCが保護されました」が出たら、「詳細情報」→「実行」を押してください（電子署名が付いていないための警告です）。
   - インストールしたくないときは、**`Kotobareach_v〇〇.zip`** を右クリック →「すべて展開」し、展開したフォルダの `Kotobareach.exe` を起動します。
2. 新しい版は、アプリの中から、ボタンひとつで更新できます（起動時に自動で確認します。「設定」→「表示設定」でオフにできます）。
3. くわしい使い方は、**[説明書](https://retzrs-ops.github.io/Kotobareach-release/)** をご覧ください。

## 動作環境

- Windows 10 / 11（64bit）
- インターネット接続（翻訳と、初回の音声認識モデルのダウンロードに使います）
- スマホ・タブレットに字幕を出すには、パソコンと同じ Wi-Fi につながるブラウザ
