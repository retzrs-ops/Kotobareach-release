コトバリーチでできること

パソコンで声を聞き取って翻訳し、その字幕を同じ Wi-Fi のスマホやタブレットに表示します。ゲーム画面はそのままに、手元の画面で会話を追えます。

相手の声（聞き取り）パソコンから聞こえる英語（ゲームの VC や Discord など）を聞き取り、日本語の字幕にします。Windows 11 のライブキャプションを読み取る方法も選べます。
自分の声マイクで話した日本語を文字にして、自然な英語に訳します。訳は Google 翻訳・Microsoft 翻訳などの無料サービスで行います。

スマホ・タブレットの画面で英文をタップすると、その端末が英語で読み上げますv1.022〜。スマホ・タブレットには何もインストールせず、ブラウザで開くだけです。

v1.022 から、パソコンからの読み上げ（トリガーキーで英語を話して VC キーを押す機能）はなくなりました。読み上げはスマホ・タブレット側で行います。

動作環境と同梱ファイル

  • パソコン：Windows 10 / 11（64bit）
  • スマホ・タブレット：パソコンと同じ Wi-Fi につながる端末と、ブラウザ（Chrome など）
  • インターネット接続：翻訳と、初回の音声認識モデルのダウンロードに使います
  • GPU（なくても動きます）：NVIDIA / AMD / Intel の GPU があれば、音声認識が速くなります。AMD・Intel はそのまま使えます。NVIDIA は「GPU」タブから追加の部品をダウンロードします（初回のみ）
ファイル中身
Kotobareach.exeアプリ本体。ダブルクリックで起動します
_internal フォルダ動くのに必要なファイルです。消したり動かしたりしないでください
Readme.txtテキスト版の説明書
別の場所に移すときは、フォルダごと移動してください。exe だけでは動きません。

はじめての設定

  1. zip を展開するダウンロードした zip を右クリックして「すべて展開」を選びます。zip を開いたままでは起動できません。
  2. コトバリーチを起動する展開したフォルダの Kotobareach.exe をダブルクリックします。青い警告画面が出たら、初回起動時の警告が出たらの手順で起動します。初回は設定ウィンドウが自動で開きます。
  3. 音声認識モデルを選ぶ「STT・翻訳」タブの「Whisperモデルサイズ」で選びます。選ぶと読み込みが始まります（初回のみダウンロード）。
    おすすめ：GPU が使える PC は large-v3-turbo、GPU がない PC は small。
  4. マイクを選ぶメイン画面の「有効な入力マイク」で、使うマイクを選びます。見つからないときは「すべての入力デバイスを表示」にチェックを入れます。
  5. 聞き取る音を選ぶ「設定」→「聞き取り」タブの「聞き取る音」で、いつも使っているスピーカー（ヘッドホン）の「パソコンの音: ～」を選びます。
  6. 閾値（しきいち）を合わせるメイン画面の音量インジケータを見ながら、すぐ下のスライダーを動かします。白い線が今の閾値です。話したときは線を超え、黙っているときは線より下になれば OK です。
  7. スマホ・タブレットをつなぐメイン画面の「タブレット接続設定」を押し、「字幕をタブレット・スマホにも送る」にチェック。出てきた QR コードをスマホ・タブレットのカメラで読み取ります。くわしくは次の章へ。
  8. （必要なら）GPU を準備するNVIDIA の GPU を使う場合は「GPU」タブでダウンロードします。くわしくはGPU で速くするへ。

設定は変えてから約1秒後に自動で保存されます。保存ボタンはありません。

初回起動時の警告が出たら

初めて起動すると、「Windows によって PC が保護されました」という青い画面が出ます。コトバリーチは無料配布のため、有料の電子署名をしていないことが理由です。ソフトの不具合やウイルスを意味するものではありません。

  1. 「詳細情報」を押す説明文の下にある文字のリンクです。「実行しない」を押すと起動せずに閉じます。
  2. 「実行」を押す「アプリ: Kotobareach.exe」と表示されていることを確かめてから押します。発行元は「不明な発行元」と出ますが、署名をしていないためです。

一度実行すれば、次からは出ません。新しい版に入れ替えたときは、また出ることがあります。

公式の配布ページ以外から手に入れた Kotobareach.exe では、この操作をしないでください。中身が書き換えられているおそれがあります。

スマホ・タブレットで字幕を見る

コトバリーチのふつうの使い方です。同じ Wi-Fi のスマホやタブレットのブラウザに、字幕を送って表示します。送るのは文字だけです。

  1. 「タブレット接続設定」ボタンを押すメイン画面のボタンです。「設定」→「タブレット表示」タブが開きます。
  2. 「字幕をタブレット・スマホにも送る」にチェックチェックは保存されるので、次回からは起動するだけで送信が始まります。送信中はボタンが緑になります。
  3. QR コードを読み取るスマホ・タブレットのカメラで読み取って開きます。読み取れないときは「URL をコピー」で URL を確かめて、ブラウザに入力します。
  4. ブックマークしておくURL は変わらないので、ブックマークすれば次からは QR 不要です（パソコンの IP アドレスが変わったときだけ読み取り直します）。

スマホ・タブレットの画面

ページ上部の画面イメージのように、上下2段で字幕が出ます。

上段：相手の声　英語 → 日本語大きく日本語、下に小さく英語の原文。
下段：自分の声　日本語 → 英語大きく英語、下に小さく日本語。

「A-」「A+」で文字の大きさ、「全画面」で全画面表示にできます。

新しい字幕が上、指で見返せる v1.023〜

上段も下段も、新しい字幕が上に出ます。指で上下にスクロールすると、過去の字幕を見返せます（上段は60件、下段は40件まで）。見返している間に新しい字幕が来ても、見ている位置は動きません。いちばん上まで戻ると、最新の字幕です。

画面を消さない v1.023〜

画面上部の「画面を消さない：オフ」を押して「オン」にすると、端末の画面が自動で暗くならず、字幕を出したままにできます。画面が消えてしまうときに使います（iPhone の Safari、Android の Chrome など）。端末の「画面の自動ロック」の設定は、変えなくて済みます。見えない小さな動画（音は出ません）を再生し続ける仕組みで、画面の右下に、小さな黒い四角が出ます。

  • 押した状態は、そのブラウザに保存されます。次回からは、最初に画面をタッチしたときに、自動でオンになります（ブラウザの決まりで、タッチなしでは始められません）。
  • 電池を使います。使い終わったら、オフにしてください。
  • iPhone の「低電力モード」では、効かないことがあります。

英文をタップして読み上げる v1.022〜

下段の英語と、上段の英語の原文をタップすると、その端末が読み上げます。もう一度タップで止まります。声は端末に入っているものを使います。

画面上部の「読み上げ設定」で次のものを変えられます（端末の中に保存されます）：声の絞り込み（男性っぽい / 女性っぽい）、アクセント（en-US・en-GB など）、声、速さ、高さ、音量、読み上げを始めるまでの間、自動で読み上げる（自分の英文 / 相手の英語 / 両方）、試し聞き、初期値に戻す。

つながらないとき

  • スマホ・タブレットが同じ Wi-Fi か確認します（ゲスト用 Wi-Fi は不可。2.4GHz と 5GHz で別ネットワークのこともあります）
  • URL が http:// で始まっているか確認します（https:// では開けません）
  • 「状態」にアクセスの記録が出ないなら、通信がパソコンに届いていません。「接続テスト」を試します
  • 「ファイアウォールの許可コマンドをコピー」を押し、管理者として開いたコマンド プロンプトに貼り付けて実行します。初めて使うときに Windows の許可画面が出たら「許可」（プライベート ネットワーク）を選びます
  • 「このパソコンの IP」で別の候補を選んでみます（VPN を使っていると複数出ることがあります）
  • ほかのソフトとポートが重なって始められないときだけ、ポート番号を変えます
URL の最後の「?t=…」は合言葉です。知らない人に見せないでください。漏れたら「合言葉を作り直す」を押し、新しい URL で開き直します。通信は暗号化されないので、外出先や公衆 Wi-Fi では使わないでください。

パソコンの画面

メイン画面にも、スマホ・タブレットと同じ上下2段の字幕が出ます。各段の見出しの右にあるボタンで、その機能をオン / オフできます。

上段：相手の声　英語 → 日本語「聞き取り: ON / OFF」ボタンで切り替えます。
下段：自分の声　日本語 → 英語「自分の声: ON / OFF」ボタンで切り替えます。聞き取りだけ使うならオフにすると PC の負担が減ります。

どちらの段も、新しい字幕が上に出ますv1.023〜。マウスのホイールで過去の字幕を見返せます（上段は40件、下段は30件まで）。見返している間に新しい字幕が来ても、見ている位置は動きません。ダブルクリックすると、いちばん新しい字幕へ戻ります。

その下に、入力マイク、音量インジケータ、閾値スライダー、稼働ステータスログ（最新10件）、「設定」ボタン、「タブレット接続設定」ボタンが並びます。

閾値の既定値は 14 です。スライダーをクリックしたあと ← → で1ずつ動かせます。

コトバリーチは同時に1つだけ起動できます。もう一度起動すると、開いている画面が前に出ます。

設定ウィンドウ

メイン画面の「設定」ボタンで開きます。開いたままでもメイン画面を操作できます。

  • 聞き取り
  • STT・翻訳
  • GPU
  • 表示設定
  • タブレット表示

聞き取りタブ

聞き取りの方法（どちらか1つ）

  • パソコンの音を音声認識する（Whisper）：ふつうの方法です。下の設定をすべて使います。
  • Windows のライブキャプションから読む：Windows 11 の「ライブキャプション」が出した英語を読み取って訳します。音声認識を動かさないので PC の負担がほとんどありません。
    • Windows 11（22H2 以降）が必要です。Windows＋Ctrl＋L でも起動できます
    • ライブキャプションの設定で、言語を「英語」に、「マイクの音声を含める」はオフにします
    • ライブキャプションの窓は閉じずに、邪魔にならない場所に置いておきます
    • この方法では「聞き取る音」「相手の言語」「認識モデル」「音量 / 閾値」は使いません

聞き取る音

「パソコンの音: スピーカー名」を選ぶと、そのスピーカーから流れる音（ゲームの音・BGM・相手の声など）をそのまま取り込みます。起動時は Windows の既定のスピーカーが自動で選ばれます。一覧にないときは「すべての入力デバイスを表示」にチェックを入れます。

相手の言語

英語 / 自動判定 / 英語だけ。日本語の動画や会話も聞こえる環境では 英語だけ を選ぶと、日本語を変な英語字幕にしてしまうのを防げます（初期設定は「英語だけ」）。

認識モデル・音量 / 閾値

聞き取り用のモデルは自分の声用とは別です。おすすめは small。ゲームが重くなるなら base や tiny に。BGM や効果音で字幕が出るときは閾値を上げます。

聞き取りの翻訳（1つ選ぶ）

  • クラウドの翻訳サービス：精度は高め。無料サービスの回数を自分の声の分に残すため、呼び出しは控えめにしています
  • ローカル翻訳 FuguMT：パソコンの中で訳します。軽くて回数制限なし。精度はやや低め。初回使用時に必要なファイルを約125MBダウンロードします
  • ローカル LLM HY-MT1.5：FuguMT より自然な訳になりやすい翻訳用 AI。先に GPU タブでダウンロード（約1.2GB）が必要です。EU・英国・韓国では使えません

モデル特徴

音声認識デバイス

「GPU（自動認識）」「GPU の名前」「CPU」から選びます。右の「実行中:」で、いま実際に使っているものを確認できます（色の意味はGPU で速くするへ）。

認識補助ワード（hotwords）

ゲーム用語や固有名詞をカンマ区切りで入れると、認識されやすくなります。例：ARC Raiders, shield, reload, raid

無料クラウド翻訳API

最初に使う無料サービスを選びます（Google翻訳 / Microsoft翻訳 / MyMemory / LibreTranslate）。失敗したら自動で次のサービスに切り替わります。「HTTP 429」（呼び出しすぎ）を受けたサービスは、しばらく休ませます。

翻訳の方法

  • クラウド優先・使えないときはローカル LLM（おすすめ・既定）
  • クラウドのみ
  • ローカル LLM のみ：回数制限なし。精度はクラウドより低めのことがあります
  • クラウド優先・使えないときはローカル翻訳 FuguMT / ローカル翻訳 FuguMT のみ（軽い）：CPU で動くので GPU のメモリを使いません。初回使用時に必要なファイルを約245MBダウンロードします

翻訳 API キー（上級者向け・任意）

自分で取ったキーを入れると、無料サービスより先にそちらを使います。キーはこの PC の Windows ユーザー専用に暗号化して保存します。「テスト」ボタンで使えるか確かめられます。

  • Gemini API キー（おすすめ）：文脈を読んで、ボイスチャット向けの自然な英語にします。Google AI Studio で Google アカウントだけで作れます。無料枠があり、無料枠で送った文は Google のサービス改善に使われることがあります
  • Google Cloud API キー：月50万文字まで無料。Google Cloud とクレジットカードの登録が必要です

翻訳の順番：Gemini → Google Cloud → 選んだ無料サービス → 残りの無料サービス

最大発話時間・無音判定の待ち時間

1回に受け付ける長さ（3〜30秒）と、話し終わりとみなすまでの無音の長さ（0.5〜3.0秒）です。

表示設定タブ

  • 字幕の文字サイズ：メイン画面の字幕欄の文字の大きさ（10〜36px）
  • 文字の縁取り：字幕の縁取りの太さ（0〜5px）。英文は単語の途中で改行しません

スマホ・タブレットの文字の大きさは、端末の画面の「A-」「A+」で変えます。

GPU で速くする

GPU で音声認識すると速くなり、精度の高いモデル（large-v3-turbo / medium / kotoba-whisper）も待ち時間をほとんど増やさずに使えます。

どちらで動いているかを確かめる

「実行中:」の色意味
緑GPU で動いています（例：NVIDIA GPU（CUDA））
青CPU で動いています（CPU を選んだ場合）
橙GPU を選んだのに使えず、CPU で動いています。マウスを重ねると理由が出ます
灰準備中（モデルの読み込み中）

メイン画面のタイトルにも [音声認識: GPU] / [音声認識: CPU] と出ます。ログには [STT 認識] (GPU 0.35秒): 右から敵が来てる のように処理時間が出ます。

AMD / Intel の GPU

追加のダウンロードは不要です。GPU ドライバーだけで動きます。GPU の名前（例：「AMD Radeon RX 9070 XT（Vulkan）」）を選んで使う GPU を決めることもできます。CPU 内蔵のグラフィックスとグラフィックボードがある PC では、グラフィックボードを優先します。

NVIDIA の GPU

追加の部品が必要です。初回使用時に必要なファイルを約1GBダウンロードします。

  1. 「GPU」タブを開くお使いの GPU が自動で表示されます。
  2. 「ダウンロード」を押す「※このPCに搭載」と書かれた行のボタンです。
  3. サイズの確認で「Yes」を押すダウンロード中もアプリは使えます。
  4. 終わると自動で GPU に切り替わる「STT・翻訳」タブの「実行中:」が緑になれば成功です。
  • 保存先は %LOCALAPPDATA%\Kotobareach。管理者権限は不要です
  • 赤字で「導入済みですが使えません」と出たら「再インストール」を、ドライバーを更新したあとは「もう一度試す」を押します
  • 「ローカル翻訳 LLM（HY-MT1.5）」（約1.2GB）も、使いたい人だけこのタブでダウンロードします

グラフィックドライバーは最新にしてください。 NVIDIA ／ AMD ／ Intel

困ったとき

「Windows によって PC が保護されました」と出て起動できない

「詳細情報」を押してから「実行」を押します。くわしくは初回起動時の警告が出たらへ。

スマホ・タブレットで字幕が開けない

同じ Wi-Fi か、URL が http:// で始まっているかを確かめます。くわしくはつながらないときへ。

スマホ・タブレットで、字幕を出している間に画面が消える

字幕画面の上部の「画面を消さない：オフ」を押して「オン」にしてください。それでも消えるときは、iPhone の「低電力モード」をオフにするか、画面をいちど開き直して、もう一度「オン」にします。

スマホ・タブレットで英文をタップしても読み上げない

端末の音量と「テキスト読み上げ」の設定（Google の音声合成エンジン、英語の音声データ）を確かめます。「読み上げ設定」で別の声に変えて「試し聞き」をしてみてください。

何も話していないのに勝手に文字が出る
  1. 閾値を少し上げます
  2. マイクの近くにファンの音やキーボードの音など、続く雑音がないか確かめます
  3. 認識補助ワードを減らすか、一度空にして様子を見ます
何も認識されない

話したときにインジケータが白い線を超えているか見ます。超えないなら閾値を下げます。インジケータが動かないなら、選んでいるマイクが正しいか確かめます。

「音声入力を開始/継続できません」と出る

「すべての入力デバイスを表示」にチェックを入れ、同じマイクの別の方式（[MME] など）を選びます。

使いたいマイクが一覧にない

「すべての入力デバイスを表示」にチェックを入れてください。

日本語の認識がおかしい・語尾が抜ける

モデルを「kotoba-whisper」にすると精度が上がります（処理は遅くなります）。ゲーム用語は認識補助ワードに入れます。

GPU が使われない（「実行中:」が橙色）
  • 「実行中:」にマウスを重ねるか、ログの [GPU] ～ を使えません: 理由 を見ます
  • NVIDIA なら「GPU」タブでダウンロード済みか、AMD / Intel なら「同梱済み」になっているか確かめます
  • ドライバーを最新にして、アプリを起動し直します。更新後は「もう一度試す」を押します
  • 「cublas」「cudnn」の文字や赤字のエラーが出たら「再インストール」を押します
追加部品のダウンロードに失敗する

ネット接続を確かめて、もう一度「ダウンロード」を押します。「検証に失敗しました」は途中でファイルが壊れたのでやり直し、「使用中です」はアプリを起動し直してからやり直します。

Google翻訳で「HTTP 429」が出る

呼び出しが多すぎて、一時的に止められています。数十分〜数時間で解除され、その間は自動で Microsoft翻訳 / MyMemory に切り替わります。話していないのに認識が走っているなら、閾値を上げてください。

聞き取り字幕に何も出ない

「聞き取り」タブのインジケータが、相手が話したときに動くか見ます。動かないなら「聞き取る音」を、実際に音が出ているスピーカーの「パソコンの音」に変えます。動いているのに出ないなら閾値を下げます。

聞き取り字幕に BGM や自分の声が出る

閾値を上げます。自分の声が出るなら、自分のマイクの音が流れるスピーカーを選んでいないか確かめます。

起動しても画面が増えない

二重起動はできません。タスクバーの Kotobareach をクリックしてください。終了直後なら数秒待ってから起動し直します。
